# 0003 · 冷灰仪器面板视觉系统

- 状态：已采纳
- 日期：2026-11-06

## 背景

第一版界面用了常见的「SaaS 仪表盘套件」语言：等距圆角卡片、统一灰投影、
大量 `A · B · C` 拼接串、五色图标。评审结论是「太丑」，且不同页面的层级读不出来。

## 决策

改用**冷灰仪器面板**语言，规则如下：

1. **底色冷灰** `#eef0f4`，面板纯白，层级靠 1px 边框与底色差，**不用投影**
2. **一个主色** `#1f4fd8`；红 `#d92d20` / 绿 `#039855` **只表达涨跌**
3. **导航为左侧边栏**：品牌区（logo + 项目名）+ 图标菜单 + 底部账号区，
   移动端降级为底部 tab；导航项由 `constants/nav.ts` 单一数据源生成
4. **统计行用连续仪表条**（`.strip`，竖向分隔线），不用四个独立卡片
5. **面板头固定 46px**，标题 13px/650，副标题 11.5px 灰，主体内容在下方连续排布
6. **数字一律 `tabular-nums`**，避免涨跌跳动时列宽抖动
7. 多字段信息用**带标签的网格**，不用中点拼接

### 导航形态的三次调整

第一版是固定侧边栏（纯文字、无图标），第二版改成顶部横向条（横向空间换垂直空间），
第二版的问题是：一级入口只有 5 个，横向条两侧留出大量空白，顶栏还被迫混装
logo、导航、指数、搜索四类信息，层级混乱。

第三版回到左侧边栏，但解决了第一版的两个硬伤：每项都有图标（折叠后仍可识别）、
支持展开（216px）/ 折叠（62px）两态，折叠状态写 `localStorage`，
平板首次进入默认折叠——兼顾「窄屏不挤压内容」与「宽屏保留文字标签」。

第四版（当前）按 agent 工具（WorkBuddy / Trae / DeepSeek Harness）的通用形态收口：

- **折叠开关搬到顶栏最左侧**。开关原本在侧栏底部，问题有两个：一是它离被控制对象
  （侧栏宽度）最远，视线要跨半个屏幕；二是侧栏底部是视线终点，却放了一个高频但
  低价值的控件，把「账号」这种身份信息挤没了
- **侧栏底部改为账号区**（头像 + 账户名 + 账户模式 + 更多），折叠后只留居中头像。
  侧栏因此只剩两件事：品牌与一级导航、当前身份
- 顶栏因此可以只承载「折叠开关 + 当前页标题 + 市场信息 + 搜索」，与侧栏分工明确

### 图标：自绘而非引入图标库

引入 Element Plus 图标集时，`Fold` / `Expand` 在 16px 下会糊成三条横线，
不同图标之间描边粗细、留白也不统一。改为在 `components/AppIcon.vue` 自绘：

- 统一 24×24 网格、`stroke-width 1.9`、`stroke-linecap round`、`currentColor`
  （1.6 太细，18px 下实际落笔不足 1.2px，抗锯齿把线条打散）
- **单图标绘制命令 ≤ 4 条**，靠轮廓而不靠细节：行情用「坐标轴 + 折线」而不是
  两根带影线的 K 线，选股用漏斗而不是三条筛选轨道 + 三个游标
- 尺寸由父级 `font-size` 控制（`1em`），侧栏 18px、底部 tab 20px

红绿的边界必须说清楚，否则会互相污染：

- 价格、涨跌幅、浮动盈亏 → 红涨绿跌（A 股习惯）
- 区间色带 → 按价格轴的空间语义：止损区在下（绿）、目标区在上（红）、建仓蓝、加仓琥珀
- 信号动作标签（建仓 / 加仓 / 减仓 / 离场）→ 蓝 / 蓝 / 琥珀 / 琥珀，**不用红绿**

最后一条是刻意为之：如果「建仓」标签是红的，而区间里的「建仓区」是蓝的，
同一张卡上同一个词会有两种颜色，用户无法建立稳定映射。

## 备选方案与被否理由

| 方案 | 否决理由 |
| --- | --- |
| 深色主题（交易终端风格） | 长时间看盘确实省眼，但表格与长文本可读性差，且打印/截图不友好 |
| 保留卡片 + 减弱阴影 | 只解决了「影子重」，没解决「所有区块看起来同等重要」的层级问题 |
| 用 Element Plus 默认主题 | 蓝色偏亮、圆角偏大、投影偏多，与数据密度不匹配 |
| 顶部横向导航条 | 一级入口仅 5 个，横向留白过多；顶栏被迫混装 logo / 导航 / 指数 / 搜索，层级混乱 |
| 引入第三方图标库 | 单页只用 8–9 个图标，包体不值；且不同图标集的描边/留白不统一，拼在一起更乱 |

## 后果

- 收益：三档断点下层级一致，短页面把页脚推到视口底部后不再出现「半截空白」
- 收益：主色唯一，新增页面不需要重新选色
- 收益：图标自绘后与文字基线对齐可控，折叠态只剩图标时不会出现「一格胖一格瘦」
- 代价：面板内不能靠投影区分浮层，`el-drawer` / `el-dialog` 需单独调阴影与圆角
- 代价：`.strip` 在移动端折行为 2×2，奇数个指标时最后一格会留白，需按 4 或 6 设计
- 代价：新增图标要手写 SVG 并遵守描边与命令数约束，不能 `import { Xxx } from '@element-plus/icons-vue'`
- 代价：账号信息只在 `≥768px` 的侧栏出现，移动端暂时无入口，后续需在底部 tab 或「更多」里补
