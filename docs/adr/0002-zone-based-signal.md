# 0002 · 用区间化信号替代买卖点

- 状态：已采纳
- 日期：2026-11-06
- 关联：SRS M06（区间计划卡）、M07（事前风控）

## 背景

主流的选股工具输出一个「买点」，用户看到的是一个精确价格。
但实际执行时价格会滑点、开盘会跳空，单点信号几乎无法按原价成交，
结果是「信号对、执行错」，使用者逐渐不再信任信号。

## 决策

信号不再是价格点，而是**带宽度、带分批、带失效条件的执行区间**：

1. 以 `ATR(14)` 作为唯一波动率标尺，所有区间宽度都是 `k · atr`
2. 四个区间在价格轴上不重叠：建仓区、加仓区、止损区、目标区
3. 建仓与加仓按 `4 : 3 : 3` 分批，每批给出价格与股数
4. 股数由**单笔风险**反推：`shares = R ÷ (建仓均价 − 止损中值)`，取整到 100 股
5. 每张卡输出赔率 `R:R`、置信度 0–100、可执行的失效条件

区间宽度不写死，随 `atr` 缩放：低波动标的自带窄区间，高波动标的自动放宽，
避免「同一个百分比止损套在所有股票上」。

## 备选方案与被否理由

| 方案 | 否决理由 |
| --- | --- |
| 单一买点 + 固定百分比止损 | 无法吸收滑点；高波动标的会被频繁扫损 |
| 固定价格区间（如 ±2%） | 与个股波动率无关，低波动标的区间过宽、高波动标的过窄 |
| 只给区间不给分批 | 用户仍需自己决定仓位，风控形同虚设 |

## 后果

- 收益：信号可直接转成委托清单（价格 + 股数 + 顺序）
- 收益：区间与风控同源，`risk/check` 校验的就是计划卡里的股数
- 代价：卡片信息密度高，需要图例与分层排版（见 ADR 0003）
- 代价：`atr` 参数（`0.45 / 0.85 / 1.15 / 1.6 / 2.8`）需要真实数据回归才能定标
