## 1. 为什么短线优先做弱转强，而不是强转更强

「强转更强」的终点是**一字板**。它的问题不是胜率，是**成交权不在你手里**：

- 一字板 / 秒板全天只有一个价位，挂单靠排队，队列里排在你前面的是隔夜就埋进去的资金。
  这类票的信号再准也没用——**能买到的那些，通常已经是行情的终点**。
- 就算偶尔排上，成本也是最高价：买在情绪最饱和的位置，容错空间为零，一根阴线就是
  −10%。它不是「高风险高收益」，是「高成本低选择权」。
- 回测里这类买点最容易自欺：日线只用开盘价成交，于是「一字板也能买到」成为默认假设。
  上一版的「打板」策略正是这么跑出 0.6% 年化的——**看起来没有 edge，实际连成交都不成立**。

弱转强买的是**弱刚被修复的那一刻**，三件事同时成立：

1. **买得进**。它昨天是「烂板」或「放量滞涨」，今天高开，说明昨天套住的人正在解套出局
   ——盘口上真的有人愿意卖，这个价位是市场给的，不是排队抢来的。
2. **阻力更小**。首日爆量或烂板已经把获利盘和套牢盘在板价附近换过一遍手；
   等到次日高开，愿意走的人昨天已经走了，剩下的持仓成本被抬到高位，抛压反而比
   「从未分歧过的首板」轻。这是「分歧转一致」比「一致加速」更容易延续的原因。
3. **止损有位置**。昨天的烂板高点、今天的开盘价都是可用的参考位，
   而一字板买进去，止损位只能拍在 −10%。

一句话：**强转更强赚的是「我比市场快」，弱转强赚的是「市场给了我一个价」。**
前者靠成交权，后者靠判断力——后者才是个人能积累的东西。

## 2. 强弱怎么判：只看两个量

强弱不是看涨了多少，而是看**量价是否背离**。统一用两条判据，全部可由日线算出：

| 形态 | 定义（可计算，与代码字段一一对应） | 判定 |
| --- | --- | --- |
| 缩量涨停 | `limit_up` 且 `volratio ≤ 0.8` | **强**。没人愿意卖，筹码锁定 |
| 放量涨停 | `limit_up` 且 `volratio ≥ 1.5` | 中性偏强。有分歧但接住了 |
| 一字 / 秒板 | 开盘即涨停（`open ≥ 昨收 × (1+涨停幅)`） | 强，但**买不到** |
| **烂板** | 盘中触及涨停、收盘没封住（`failed_limit`） | **弱**。板上在出货 |
| **放量滞涨** | `volratio ≥ 2` 且 `change_pct ≤ 6` | **弱**。放出来的是卖方 |
| 缩量整理 | `volratio ≤ 0.8` 且振幅 ≤ 5% | 弱（蓄势），但不是「转强」的弱 |

规则直接对应「放量视为弱、不放量视为强」：

- **同样是涨停，缩量的比放量的强**。放量涨停说明有人在板上卖给你；
- **同样是上涨，放量的比缩量的弱**。涨 3% 却放出两倍量，是有人在借流动性出货；
- **烂板是弱的最强形式**：它已经证明「有人愿意打上去」，也证明了「打上去就有人卖」。

「弱」必须是**或**的关系——烂板是一种弱，放量滞涨是另一种弱，两者互不包含。
所以条件系统新增了 `any` / `all` 组节点（`conditions.py`），否则策略只能二选一，
等于把一半的机会丢掉。

## 3. 出手节点

**T 日收盘**（选股）：筛出当日呈「弱」形态、且位置不高的票 → 生成计划卡。
**T+1 日 9:25 竞价**（买点）：开盘价就是集合竞价撮合价，用它判高开幅度：

```
高开幅度 = 开盘价 / T日收盘 − 1
```

| 高开幅度 | 结论 | 动作 |
| --- | --- | --- |
| < +1% | 弱势没被修复，信号不成立 | **不做**（`gap_weak`） |
| +1% ~ +7% | 弱转强成立 | **开盘买入** |
| > +7% 或直接一字 | 情绪已透支 / 买不到 | **不做**（`gap_high` / `limit`） |

「快速拉板」这一步，日线数据里没有分时，**测不了**，所以不写进买点：
写了就是一个无法验证的条件，只会让回测和实盘继续分叉。
它被拆成两件事——买点用「高开幅度」代理（竞价结果已经包含隔夜情绪），
封板结果只在收盘后作为**验证指标**记录，不参与买入决策。

## 4. 买点与排除条件（可直接对照代码）

入场（全部满足）：

| 条件 | 阈值 | 为什么 |
| --- | --- | --- |
| 昨日形态是弱 | `failed_limit` 或（`volratio ≥ 2` 且 `change_pct ≤ 6`） | 见第 2 节 |
| 今日没封板 | `limit_up == false` | 已封死的票次日大概率一字，买不进也没有折价 |
| 没崩 | `change_pct ≥ −5%` | 接近跌停是「崩」，次日高开是超跌反抽，没有承接 |
| 位置不高 | `mom20 ∈ [−5%, +35%]` | 要「启动初期的第一次分歧」，不接高位第三次分歧 |
| 有量 | `amount ≥ 0.5 亿` | 接不住单的票谈不上放量 |
| 高开区间 | `gap ∈ [+1%, +7%]` | 见第 3 节 |
| 买得到 | 非一字涨停 | 一字板没有成交权 |

排序（不是准入）：行业涨停家数 → 行业涨幅 → 行业内排名分位 → 量比。
同一天可能几只都成立，优先给**行业里正在抱团**的那只——弱转强能不能成，
题材强度比个股形态更说了算。（主力净流入原本也在这条链上，但它只覆盖 3% 的
票和 3 个交易日，权重会因覆盖率不足被回测自动摘掉，故换成行业内排名分位。）

排除：ST、停牌（无当日 K 线）、购买权限未开通的板块、连续涨停 ≥ 3 天的票
（那已经不是「弱」）。最后一条由「昨日形态是弱」自动满足——`failed_limit`
与放量滞涨都要求当日**收盘没封板**，连板股进不了候选池，不需要再写一条条件。

### 「当日必须封板，不封次日走」——默认关闭，这是实测结论

这条规则在本轮被完整实现（`need_limit_close` + `limit_close_frac`），但**默认不开**：

| 配置 | 年化 | 回撤 | 卡玛 | 胜率 |
| --- | --- | --- | --- | --- |
| 不强制（默认） | **14.33%** | −18.50% | **0.78** | 52.6% |
| 不封板清仓 | −1.13% | −24.29% | −0.05 | 42.3% |
| 不封板减半 | −2.79% | −22.45% | −0.12 | 43.2% |

换 6 组买点参数重跑，6 组一致变差。原因在 T+1：**当天买的当天卖不掉**，
「没封板」这个事实要到收盘才知道，成交只能等次日开盘——而那正是弱势里最差的
价位之一。样本里未封板的单子平均每笔 **−5.7%**，封板率只有 **16%**，
付不起这个成本。

所以它是**开关**而不是规则：复盘每天记「出手几只、封板几只」，
等封板率稳定在 35% 以上（强势期会明显回升）再打开。这条判断本身是可验证的，
不需要凭感觉。

## 6. 复盘 → 总结 → 迭代 → 自进化

四步闭环，每一步都落在具体字段上，不靠感觉：

1. **记账**（每个交易日 15:05，`autopilot.run_eod`）
   推进模拟盘 → 逐票写清「今天买的那只收盘赚了还是亏了、明天怎么操作」→
   记录计划执行率、滑点、以及弱转强族的**封板率**。
2. **复盘**（`aiwatch.analyze_review`）
   事实（市场宽度 / 账户 / 持仓逐票 / 计划执行 / 封板率）→ 模型写成一段可读的判断。
   硬性要求：有持仓就必须谈到今天买的那只票的盈亏与明日动作。
3. **总结**（`plan_history` + `plan_health`）
   成交率、平均不利滑点、封板率滚成 20 天窗口。这不是给人看的报表，
   而是第 4 步采纳参数前的门槛之一。
4. **迭代**（`harness.evolve` + `paper_verdict`）
   对 `PARAM_KEYS`（top_n / 行业上限 / ATR 三档 / 时间止损）做遗传搜索，
   **采纳必须同时满足**：样本外打赢 + 本身赚钱 + 风控达标 + 模拟盘执行质量没有系统性偏坏。
   一周内不重复采纳同一条结果，避免用一天的噪声调模型。

**结构参数不进搜索**：`gap_band`、`need_limit_close`、`weak_participate` 是策略的
**性质**，不是待调参数。让遗传搜索去挑「弱市该不该做」「高开多少才算数」，
等于让它挑这段行情是牛是熊——样本外一定还回去。它们只能由人根据第 5 节的
证据来改。

## 7. 实测（1260 个交易日，2021-09 ~ 2026-11，沪深300 −17.7%）

同口径：真实购买权限（只开主板）、池 600 只、成交价 = 次日开盘价（含 5‱ 滑点）。

| 策略 | 年化 | 回撤 | 卡玛 | 胜率 | 笔数 | 平均仓位 |
| --- | --- | --- | --- | --- | --- | --- |
| 弱转强 `w2s` | 14.33% | **−18.50%** | 0.78 | 52.6% | 268 | **28%** |
| 板块联动 `sector` | 26.69% | −22.93% | 1.16 | 63.4% | 235 | 37% |
| 缩量蓄势 `squeeze` | 15.58% | −18.08% | 0.86 | 56.8% | 222 | 40% |
| 趋势波段 `trend` | 22.72% | −23.64% | 0.96 | 57.5% | 268 | 42% |

诚实地说：**弱转强的收益不是最高的**，卡玛 0.78 也排在另外三条之后。
它的价值在两处——回撤最浅（−18.50%）、仓位最低（28%），因为它的信号最稀，
买点又硬性要求高开区间，天然少做。这三点合起来才是「更抗跌的进攻仓」，
单看年化会低估它。

另外一条必须记下来：这四条策略的 ATR 三档与持有上限统一走 `DEFAULTS`
（2.2 / 2.6 / 5.0 / 20）。此前每条写了自己的 1.4~1.8 ATR、4~6 天，
而 `run_backtest` 当时只从 spec 读结构参数——**这些档位从未被回测检验过**，
模拟盘按紧档位跑、回测按 DEFAULTS 跑。补齐之后扫了一遍（sector：
stop 1.4/1.8/2.2 × 持 5/10/20），9 个格子里越紧越差且单调：
1.4ATR+5 天 年化 2.64%（回撤 −43.2%），2.2ATR+20 天 26.69%（回撤 −22.9%）。
换句话说这几条策略的 edge 来自「拿住」，把它们短线化就是把它杀掉。

## 8. 已知边界

- **日线拿不到分时**：秒板、撤单、封单强度、竞价量都无法回测。所以「快速拉板」
  被拆成「高开幅度（买点）」和「是否封板（事后验证）」两件事，不写成买点条件。
  将来若接入分时历史，可以把封板时间补进验证指标，但不能反过来改买点——
  买点必须在 9:25 就能判定，否则回测和实盘立刻分叉。
- 涨停幅度按板块取（主板 10% / 双创 20% / 北交所 30% / ST 5%），
  复权价的涨跌幅有零点几个百分点误差，判涨停留了 0.2% 容差。
- 样本是熊市。弱转强的封板率在强势期会明显更高，第 5 节的开关就是为那一刻留的。
- 一键回测与实盘的成交假设仍然偏乐观：日线只有开高低收，成交价一律按开盘价。
  这一点对所有策略一视同仁，比较时成立，绝对值要打折看。
