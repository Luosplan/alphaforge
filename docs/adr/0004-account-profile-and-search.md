# 0004 · 账户口径进入风控，搜索改为多通道检索

- 状态：已采纳
- 日期：2026-11-06
- 关联：SRS M11（全局搜索）、M09（事前风控）、M14（账户）

## 背景

两件事一起改，因为它们都指向同一个问题：**界面上看到的信息，和执行时用的口径不是同一份**。

1. 全局搜索"点了没反应"。排查后发现是两个独立缺陷叠加：
   - `MarketView` 在 `setup` 里读一次 `route.query.code` 就再也不看路由。
     搜索跳转是同一路由只改 query，Vue 复用组件不重新 `setup`，
     于是**已经在行情页时再搜一次，画面完全不动**。
   - 搜索弹窗挂在 `el-dialog` 默认的渲染位置上，而顶栏有
     `backdrop-filter: blur()`。`backdrop-filter` 会为后代建立包含块，
     弹窗的 `position: fixed` 因此被限制在 58px 高的顶栏内，被裁成一条。
2. 手续费、可买板块这些"账户属性"原本散落在 `constants.py` 里写死，
   用户无法按自己的券商与权限配置，估算的费用和执行的口径对不上。

## 决策

### 搜索：多通道 + 相关度排序 + 路由联动

1. **检索通道**：代码（含不带后缀）、名称、拼音首字母、全拼、行业。
   拼音不做运行时依赖，`universe.PINYIN_ALIAS` 里 40 行的静态表就够——
   为一个检索功能引入 pypinyin 不划算，新增标的补一行即可。
2. **打分只排序不改集合**：完全相等 > 前缀 > 包含；代码命中优先于拼音命中。
   多关键词空格分隔且需同时命中，避免「中国 石化」把中国石油带出来。
   同分时按流通市值降序，「中国」的第一条是中石油而不是中国中车。
3. **前端三处配套**：请求带序号丢弃过期响应（防抖不防乱序）、
   弹窗 `append-to-body` 逃出顶栏的包含块、`MarketView` 监听 `route.query.code`。
4. 选中标的**回写 URL**（`router.replace`），刷新、分享、前进后退都能还原。

### 账户设置：进入风控链路

个人设置不是一个展示面板，三项设置各有一条实际作用路径：

| 设置 | 作用路径 |
| --- | --- |
| 成本口径（佣金 / 最低佣金 / 印花税 / 过户费 / 滑点） | `trade_fee()` → 风控卡预估费用、手工记账扣费 |
| 购买权限（5 个板块开关） | `check_plan()` 追加 `BLOCK` 事件；`store.add_trade()` 抛 `ValueError` → 400 |
| 账户名称 | `sys/meta` 的账户身份，侧栏账号区展示 |

板块键 `sh_main / sz_main / gem / star / bse` 由 `universe.board_key()` 统一推断，
前后端共用；板块中文名来自 `constants.BOARD_META`，UI 不硬编码。

## 备选方案与被否理由

| 方案 | 否决理由 |
| --- | --- |
| 只在搜索弹窗里修 `router.push` | 换页面能跳、换股票不能跳，缺陷只修一半 |
| 把搜索做成独立路由页 `/search` | 检索是随处可用的横切能力，独立页要多一次进出，还占一个导航位 |
| 用 `pypinyin` 运行时算拼音 | 为一个输入框加一份词库与冷启动开销，40 只标的用不上 |
| 购买权限只做 WARN 提示 | 提示不阻断等于没配置，用户仍会照着计划卡下单 |
| 手续费只留佣金一项 | 印花税在卖出侧占比最大，缺了它「费用」就没有参考价值 |

## 后果

- 收益：搜索从「代码/名称精确包含」变成可用的检索，且任何页面都能跳转到正确标的
- 收益：费用与权限只有一份来源，`data/store.json` 持久化，重启不丢
- 代价：`PINYIN_ALIAS` 是手工静态表，新增标的必须同步补一行（已在注释里注明）
- 代价：北交所默认关闭，首次进入时该板块标的会显示「未开通 · 不可买」，
  这是刻意的：实盘本来就需要单独开通
- 已知未做：`seed_trades()` 里的历史流水仍按默认费率生成，
  它代表"当时发生的成交"，不随当前设置回溯
