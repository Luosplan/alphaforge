# 0011 · 第三条战法「一进二」与实验室左栏战法清单

- 状态：已采纳
- 日期：2026-11-27
- 影响：`selector.STRATEGIES` 增到三条（`daban` / `second` / `trend`）；
  `autopilot._strategy_ids()` 改为「当前策略集」而不是「已有账户的策略」；
  `store` 新增 `lab_order`，`lab_store` 新增 `purge()`；实验室页面从
  「矩阵 + 全策略计划卡 + 详情抽屉」改成左右两栏

## 1. 问题

### 一进二没有落点

0009 把弱转强降级成打板的**出手时间**（次日高开 1%~7%）。这条口径对，但它把两件不同的
事塞进了同一条策略：

- **打板**：在今日涨停池里按连板高度取前 3，次日高开 1%~7% 就按。它的池子里既有首板、
  也有 4 板 5 板。
- **一进二**：只做**昨日首板**的那一只。它要的不是「连板梯队里最高的」，而是「刚封过
  一次板、今天高开被承接」这个窄口——`二板以上` 在这个口径里是噪声，甚至是有害的：
  高位连板在弱势里接力失败的概率远高于首板。

同一条策略不可能同时表达这两种选股池，所以「一进二」在 0009 之后一直没有独立的
账户、独立的进化、独立的胜率统计——它在复盘里也永远混在打板那一格里。

### 新战法是死的

`_strategy_ids()` 当时读的是**已有账户的策略**。后果是：新增一条战法，在有人手工点开、
手工推进一次之前，它不会被盯盘、不会被推进、不会被进化。用户看到的就是「左边有这个
tab，但它永远没数据」。

### 策略越多，页面越乱

三条战法摆成三张大卡片、再加一块「全策略计划卡」、再点开抽屉看详情，同一件事摊在
三个地方。加上顶部那条「策略数 / 平均胜率 / 最优卡玛 / 模拟盘总净值」，首屏几乎全是
汇总数字，反而看不见「今天到底选了什么」。

## 2. 决策

### 一进二独立成一条战法

| 项 | 口径 | 理由 |
| --- | --- | --- |
| 选股池 | `limit_up = True` 且 `pool_limit_min = pool_limit_max = 1` | 只留昨日首板。二板以上在这一条里是噪声，不是更好的标的 |
| 出手时间 | 次日开盘高开 **1%~7%**（`gap_band`） | 与打板同一套承接逻辑，但只作用在首板上 |
| 排序 | 同行业涨停家数 0.34 / 量比 0.26 / 行业当日均涨 0.22 / 行业内排名分位 0.18 | 首板没有连板高度可排，只能比「它所在行业今天有多热」和「它自己有没有量」 |
| 持仓 | `top_n = 3`、同行业上限 2、时间止损 3 天、不加仓 | 与打板一致：一次确认过的下注 |
| 择时 | 不看大盘（`market_ma = 0`） | 涨停潮本身就是情绪指标 |

### 推进对象改成「当前策略集」

`_strategy_ids()` 现在的口径：

- 内置战法（打板 / 一进二 / 波段）**一律在列**，没开户也进。收盘那一步会顺手建账户，
  所以新加的战法第二天就有数据，不需要人去点。
- 自定义战法**只在已经有账户时**在列。它们是用户临时试的一条定义，全塞进进化预算里
  会把收盘任务拖长几倍，而用户根本没打算让它们天天跑。
- 已删除策略的旧账户仍然挡在外面（0009 之后就有的那道门）。

### 实验室拆成左右两栏

- **左栏**只回答「有哪几条」：名字、内置/自定义、区间收益、模拟盘盈亏、计划卡张数。
  顺序可拖，整份存 `store.json` 的 `lab_order`。顺序只是给人看的，不参与任何计算——
  盯盘与推进按策略集遍历，不按这个顺序。
- **右栏**只回答「这一条现在怎么样」：头部指标 + 今日计划卡 + 回测 / 模拟盘 / 自进化。
  详情抽屉去掉，内容原样搬进右栏；切战法只换数据，不换页签。
- 顶上那格「全部战法」是汇总视图：一览表 + 全策略计划卡，跨策略的对比仍然看得到。
- 「战法数 / 平均胜率 / 最优卡玛 / 模拟盘总净值」挪到**持仓页**，与持仓、净值并排——
  它们是「这套系统跑到什么水平」的同一层问题。

## 3. 代价

- 一进二和打板的候选池会重叠：一只昨日首板、今日高开的票，两条策略都会选中它。
  这是有意的，页面上按「N 策略共选」标出来，不去重。
- 内置战法不可删（`DELETE /lab/strategies/{id}` 返回 400）。它们写在代码里，删掉要改
  代码；要改口径就走编辑器的「另存为副本」，副本是自定义战法，可以删。
- 进化名额从两条变三条，收盘任务变长。进化窗口 60 天、单轮几十秒，暂时够用；再加战法
  就要考虑把进化改成排队跑，而不是串行跑完。
