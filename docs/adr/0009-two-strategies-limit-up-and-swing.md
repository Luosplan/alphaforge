# 0009 · 策略集收敛为「打板 + 波段」

- 状态：已采纳
- 日期：2026-11-23
- 影响：`selector.STRATEGIES` 从四条收到两条（`daban` / `trend`），删除 `squeeze` /
  `sector` / `w2s`；`harness` 搜索区间锁定 `top_n` 与行业上限、`time_stop` 按策略
  声明收窄，进化窗口 60 天；`backtest` / `paper` 新增 `allow_add` 与 `weak_huddle`
  两个策略属性；`MODEL_VERSION` → 13

## 1. 问题

上线后暴露三件事，指向同一个根因：**策略集把「买什么」和「什么时候买」混在了一起**。

- 最强的行情里一只涨停股都选不出来。四条策略里唯一与涨停相关的是 `w2s`（弱转强），
  而它的条件是 `limit_up = False`——把当日涨停的票全部排除在外。于是「今天 36 家涨停」
  这种日子，选股结果里一只板都没有。
- 模拟盘连续多日零成交。`trend` / `squeeze` 在沪深300 跌破半年线后停手，`sector` 的
  抱团准入在弱势里几乎不成立，`w2s` 的高开区间又卡掉大部分候选。四个账户、四条策略，
  真正会挂单的只有半条。
- 自进化窗口 250 天，一轮几分钟。两条策略串起来十几分钟，收盘任务经常撞上重试上限；
  参数在下跌段里永远不满足「样本外必须赚钱」，于是天天跑、从没换过。

## 2. 决策

**只保留两条策略：打板、波段。弱转强不是策略，是打板的出手时间。**

### 打板

| 项 | 口径 | 理由 |
| --- | --- | --- |
| 选股池 | `limit_up = True`，按 `limit_cnt` 降序取前 3 | 不选涨停股就不叫打板。连板高度是这一池里最该排前面的一列 |
| 出手时间 | 次日开盘高开 **1%~7%** | 低开说明昨天的板没人接；高开越过 7% 已接近一字，买不到也没溢价 |
| 择时 | 不看大盘位置（`market_ma = 0`） | 涨停潮本身就是情绪指标。指数在半年线下方时照样有连板梯队，用滞后指标去否掉当天最热的票是错的 |
| 加仓 | 不加（`allow_add = False`） | 持仓只有「封住了继续拿 / 没封住走」两种结局，中途加钱等于把一次确认过的下注改成两次没确认的 |
| 不封板离场 | **关**（`need_limit_close = False`） | T+1 下当天卖不掉，「没封板」要到收盘才知道，成交只能等次日开盘——最差的价位。实测打开后 250 天年化 62.6%→47.4%，最近 60 天 −46.9%→−66.0% |

### 波段

保留原有中期动量选股（`mom5 ≤ 12`、`mom60 ≤ 45`、`volratio ≥ 1.3`、`mom20 ≥ 8`、
站上 20 日线），只改两处：

- 弱市**半仓参与**，不再停手。实测 250 天窗口：停手年化 66.4% / 回撤 −23.9%，
  参与年化 79.4% / 回撤 −18.4%；750 天窗口 43.6% / 36.1%，差距收窄到可接受。
  而停手的代价是账户在指数长期站不回去时几个月零成交，闭环空转。
- 弱市不加「行业抱团」门槛（`weak_huddle = False`）。抱团准入是为板块联动型策略
  设计的；波段靠个股动量，今天选出的抗跌大票所在行业本来就没涨停，硬套等于一只不买。

## 3. 自进化：改成每天跑

- 窗口 **60 天**。目标是持有 1~6 天的短线策略，60 天跨得过一次风格切换；再长就是
  拿几个季度前的行情调今天的参数。单轮从几分钟降到几十秒，收盘后能完整跑完。
- 采纳门槛跟着窗口调整：了结交易 ≥ 6 笔（按样本外天数折算）、平均仓位 ≥ 20%、
  样本外「赚钱或比基线少亏」。原来的「样本外必须赚钱」在下跌段里会让参数永久冻结。
- 搜索区间锁定：`top_n` 与 `max_per_industry` 完全等于策略声明值，`time_stop` 只在
  声明值 ±几天内动。第一版没锁，收盘跑完一轮，打板的 `time_stop` 从 20 被搜到 50——
  那不是优化，是把打板改成了中线。

## 4. 代价

- `MODEL_VERSION` 升到 13，旧回测与旧进化结论全部作废。这是刻意的：选股池与撮合
  条件同时变了，两套口径的数字并排显示比没有数字更危险。
- 打板在 60 天弱势窗口里是负收益（−13.8%）。这不是缺陷，是打板在下跌段的真实表现；
  用 250 天窗口看它是 +62.6%。页面默认回测 750 天，看到的是长期水平。
- 删掉的三条策略不是「不好」，是定位重复。缩量蓄势与板块联动首日的买点逻辑没有被
  否定，只是它们不该与打板共用同一批账户、同一套进化名额。
